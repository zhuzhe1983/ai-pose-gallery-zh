# WaveSpeed pose references

Selected from [WaveSpeed AI Pose Gallery](https://wavespeed.ai/free-tools/ai-pose-gallery/sitting-floor), checked 2026-11-06.

Nine floor-sitting poses, each with front, three-quarter and side views in both mannequin and line-art styles. These are reference images, not downloadable 3D meshes or verified reconstructions. The three images in a group can contain inconsistencies.

The source gallery permits personal and commercial reference use and says not to resell the images alone as a pose pack. These images remain subject to the source's terms; the repository's code license does not relicense them. This project is not affiliated with or endorsed by WaveSpeed AI.

`selection.json` records the original names and asset identifiers. `sources.json` records the original URLs and SHA-256 hashes. Display PNGs are lossless re-encodings of the original WebP files, and thumbnails are resized JPEGs. Names are translated into Chinese and Japanese. Reproduce using `scripts/import-wavespeed.py` with Pillow.
