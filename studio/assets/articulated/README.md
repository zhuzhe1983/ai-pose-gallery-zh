# Articulated display mannequins

Default runtime revision: `articulated-v1`. Adult female/male anatomy derives from the project's [CC0 MakeHuman assets](../humans/README.md). The original source and its provenance are retained. These derivatives remain CC0-1.0; see [license](../humans/LICENSE-CC0.txt).

The faceless oval head, rigid limb shells and spherical joint connectors are generated by `scripts/build-articulated-models.py`. Surfaces retain the anatomical proportions and bind pivots; hands retain weighted finger bones and the trunk retains continuous spine/neck deformation. Shell and joint colors share one vertex-colored material, one mesh per actor, and two shared geometries across up to six actors. No cloth simulation is used.

The editor retains independent pelvis, waist, mid-spine, chest, neck and head pivots, paired limb joints and three bones per finger. Existing scene parameters and photo fitting remain compatible. Extreme bends can expose shell overlaps; this is a display mannequin, not a mechanically simulated or collision-constrained doll.

Rebuild with Blender 5.2:

```sh
blender --background --factory-startup --python scripts/build-articulated-models.py
```

The generator only reads the shipped CC0 assets; it downloads no model or reference image. The WaveSpeed images and the user's style reference are not embedded in these meshes.
